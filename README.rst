This repository is a modified fork of the NIST CDCS `core_explore_keyword_app <https://github.com/usnistgov/core_explore_keyword_app>`_
(exploration by keywords for the curator core project), used by the AsphaltMine (AM) web application.

Modifications
=============

This fork includes modifications for AsphaltMine, in place since 2024-05-15. For the detailed
nature and dates of changes, see this repository's commit history.

Original NIST core_explore_keyword_app
=======================================

For the unmodified original, see ``ORIGINAL_README.rst`` and
`https://github.com/usnistgov/core_explore_keyword_app <https://github.com/usnistgov/core_explore_keyword_app>`_.
